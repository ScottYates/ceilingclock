Firmware & everyday use

Flash once over USB. After that, updates, alarms, sounds and display settings all happen from your phone.

See it running

The real firmware running in the PC simulator (no hardware), showing the phone page's live view through an alarm: ringing, snooze, then flipping the projection upside down and back. The ceiling picture stays readable while the projector module's own digits are mirrored.

Flash the firmware

Easiest, no install (Chrome or Edge on a computer):

  1. Download ceilingclock-esp32s3-factory.bin (2.5 MB). It's the complete image: bootloader, partition table and firmware.
  2. Connect the ESP32-S3 by its port marked USB, with the 5 V supply unplugged.
  3. Open Espressif's web flasher at espressif.github.io/esptool-js, set the baud rate to 921600 and click Connect. Pick the board's serial port. If it doesn't connect, hold BOOT, tap RST, release BOOT and try again.
  4. Under Program, set the flash address to 0x0, choose the downloaded file and click Program. When it finishes, press RST.

Or build it yourself with PlatformIO:

  1. Install VS Code and the PlatformIO IDE extension.
  2. Download the repository (zip) and open the firmware/ folder in VS Code.
  3. Connect the board as above and click the PlatformIO Upload arrow. The first build downloads the toolchain and libraries, which takes a few minutes.
  4. Open the serial monitor (115200 baud) to watch it start.

Connect it to Wi-Fi

  1. On first boot the projector shows WIFI SETUP.
  2. On your phone, join the Wi-Fi network CeilingClock-Setup. A setup page opens (or go to 192.168.4.1). Pick your home network and enter its password.
  3. Once it's connected, open http://ceilingclock.local/. On Android, use the IP address shown in the serial monitor or your router, and reserve it in the router so it doesn't change.

Later updates: upload ceilingclock-esp32s3-update.bin (or your own .pio/build/esp32s3/firmware.bin) in the page's Firmware update box. Alarms and sounds are kept.

Try the web page

Live demo: the actual firmware compiled to WebAssembly, running in your browser with simulated hardware. The page is the same one the clock serves. A control bar lets you fast-forward time, press the buttons and change the room light. Two differences from the real clock: it uses your browser's time zone, and it forgets everything when you reload.

On your computer: the simulator also builds as a normal Linux or Mac program, keeping its files in a folder. Run pio pkg install in firmware/, then make run in firmware/sim/, and open localhost:8080.

The clock's web page

Open http://ceilingclock.local/ (or the clock's IP address) on your phone. Every change saves itself; there are no Save buttons.

Troubleshooting

SymptomFix
Build error undefined reference to vtable for DecoderMake sure src/audio_lib_fix.cpp is present. The audio library (pinned to 4.0.1 in platformio.ini) leaves two functions undefined, and that file supplies them.
Projector and front display show -- --No Wi-Fi and no RTC time yet. Check the DS3231 wiring; the page should say "RTC backup ok".
Ceiling digits too faintThe projected digits are meant for a dark room. Set the projector's brightness to 7, focus carefully, and keep the lens clean. Light from a lamp or a window will wash them out.
Ceiling digits lean the wrong wayMany TM1637 modules have slanted digits; mirroring flips the slant. Nothing is wrong.
No soundCheck the amplifier has 5 V and the speaker is connected, then press Play on beep.wav. If your own file won't play, re-save it as 44.1 kHz MP3.
Resets when the alarm startsThe power supply is too weak or the wires too thin. Try a lower alarm volume, and check the 100 µF capacitor is at the amplifier.

Build status: the firmware compiles for the ESP32-S3 (74% of program space, 20% of RAM) and runs in the PC simulator. It runs on a breadboard build (version 2.0.0, with both displays and the amplifier).
