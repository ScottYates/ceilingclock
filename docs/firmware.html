Firmware & everyday use

Flash once over USB. After that, updates, alarms, sounds and display settings all happen from your phone.

Flash the firmware

  1. Install VS Code and the PlatformIO IDE extension.
  2. Download the repository (zip) and open the firmware/ folder in VS Code.
  3. Connect the ESP32-S3 by its port marked USB, with the 5 V supply unplugged.
  4. Click the PlatformIO Upload arrow. The first build downloads the toolchain and libraries, which takes a few minutes. If it can't connect, hold BOOT, tap RST, release BOOT, and try again.
  5. Open the serial monitor (115200 baud) to watch it start.

Connect it to Wi-Fi

  1. On first boot the projector shows WIFI SETUP.
  2. On your phone, join the Wi-Fi network CeilingClock-Setup. A setup page opens (or go to 192.168.4.1). Pick your home network and enter its password.
  3. Once it's connected, open http://ceilingclock.local/. On Android, use the IP address shown in the serial monitor or your router, and reserve it in the router so it doesn't change.

Later updates: build with pio run, then upload .pio/build/esp32s3/firmware.bin in the page's Firmware update box. Alarms and sounds are kept.

Settings page

SettingWhat it does
Alarms (up to 8)Time, days (none = one-time), sound, volume 0–21, fade-in seconds, sunrise minutes, snooze minutes, auto-stop minutes. Each alarm also has Skip next and Ring now.
Front display / projector modeAlways on, Always off (fully dark), Only at night, Only in daytime, with separate day and night brightness.
Turn displays on while an alarm ringsOverrides "off" while an alarm is going off. Untick it to keep them dark.
Night hours / light sensorChoose the night window. You can also treat a dark room as night; the page shows the live sensor reading to help you set the threshold.
Mirror / flip / bright digits on dark / LCD contrastMake the ceiling image read correctly and look as clean as possible.
SoundsUpload MP3, WAV, M4A/AAC, FLAC or OGG (about 9.9 MB of space). The built-in beep can't be deleted, so there's always a fallback.
Time zone / NTP serverDefaults to US Central (CST6CDT,M3.2.0,M11.1.0) and pool.ntp.org. Other zones: POSIX TZ list.
Web passwordBlank means no login. If set, the user name is admin.

Troubleshooting

SymptomFix
Build error mentioning Audio, setVolume or connecttoFSThe ESP32-audioI2S library changes often. Pin a release by adding #<tag> from its GitHub releases page to the library URL in platformio.ini.
Build error on ledcAttachOld Arduino core 2.x. Update the espressif32 platform in PlatformIO.
Build error on sntp_set_sync_interval or sntp_restartUse the esp_sntp_… names instead.
Projector shows NO TIME YETNo Wi-Fi and no RTC time yet. Check the DS3231 wiring; the page should say "RTC backup ok".
Bright rectangle with dark digitsTick Bright digits on dark, raise LCD contrast, and tape over the glass border.
LCD turns black or blotchyIt's too hot. Lower the projector brightness and check the tower vents aren't blocked.
No soundCheck the amplifier has 5 V and the speaker is connected, then press Play on beep.wav. If your own file won't play, re-save it as 44.1 kHz MP3.
Resets when the alarm startsThe power supply is too weak or the wires too thin. Lower the sunrise max brightness.

The firmware hasn't been compiled yet. Its scheduling logic is unit tested (firmware/test), but expect to fix one or two library-version errors on the first build. The table above lists the likely ones.
